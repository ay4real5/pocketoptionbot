Checking local API setup…

API setup and privacy

Add OPENAI_API_KEY=your_key to this project's local .env file, then restart the dashboard. Never paste your key into chat or commit it. This page never receives the key.

Provider: OpenAI. Model: GPT-4.1 mini. API billing is separate from ChatGPT. A cropped chart is sent through your local server, normally once every 30 seconds, with a faster initial asset confirmation after 10 seconds and a server-wide cap of 60 attempts per hour. These in-memory limits reset if the server restarts; set a provider budget too.

The app does not save images. Requests use store: false; this does not override the provider's abuse-monitoring or retention policies. Stop prevents future uploads, but cannot recall an image already sent.
